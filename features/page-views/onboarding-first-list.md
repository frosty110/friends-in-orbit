# Make your first list

**Route:** `onboard/first-list/{listId}`
**Group:** Onboarding
**Status:** active
**Last reviewed:** 2026-10-05
**Index:** [Page views](../PAGE_VIEWS.md)

What a user expects to see or do here:

- Name the list and pick at least 3 people to finish
- Use the same configuration controls as the real Edit-list screen
- Finish ("Done") or add another list (a new, empty one; the finished list is kept)
- Clear gating: can't finish without a name + 3 members
- See a snackbar after a change, such as "Removed {name}" with Undo, which puts them back
- Going back to Sync, or reopening the app mid-setup, leads back to this same list, never a second copy
