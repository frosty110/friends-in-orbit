# Search

**Route:** `search`
**Group:** Settings & data
**Status:** active
**Last reviewed:** 2026-10-05
**Index:** [Page views](../PAGE_VIEWS.md)

What a user expects to see or do here:

- Search everyone by name or number (debounced), with a "Find someone" hint before typing
- Tap a result to open the contact, or dial from the row's phone icon (muted, not accent; rules.md Design 6 allows a quiet one on each row)
- See which lists each person is on, or "Not on any list", and "Add to list"
- "Nothing matches" only when the query really has no hits; a skeleton while contacts load; "Couldn't search right now" with Try again if reading fails (BROWSE-06 in [browse](../browse/README.md))
