# Settings

**Route:** `settings`
**Group:** Settings & data
**Status:** active
**Last reviewed:** 2026-10-05
**Index:** [Page views](../PAGE_VIEWS.md)

What a user expects to see or do here:

- Nothing until the saved settings load, then the real values (no flash of defaults; SET-09)
- Choose a theme (Warm, Cool, Forest, Plum, Mono, or Wallpaper, which follows the phone's wallpaper), light or dark, and fine-tune the accent
- See and fix each permission (Contacts, Call log, Notifications)
- Toggle call sync; set how far back to import (30 to 365 days)
- Set where the contact picker's groups begin ("Groups when adding people": Commonly called, Rarely called, Recently added, Long gap; SET-10)
- Open Ignored contacts and Call history
- Export or import an encrypted copy of the data (passphrase)
- Reset all data (with confirmation)
- About: version, feedback email, source code, open source licences
