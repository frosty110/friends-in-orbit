# Preview your first list

**Route:** `onboard/preview`
**Group:** Onboarding
**Status:** active
**Last reviewed:** 2026-10-05
**Index:** [Page views](../PAGE_VIEWS.md)

What a user expects to see or do here:

- See 5–10 people Orbit suggests from recent contact
- Untick anyone to exclude; select/deselect all at once
- Make the suggestions into a first list, or start blank
- If a first list is already under way, either button continues it: a typed name is kept and people are only added
- Auto-skips when there aren't enough candidates
